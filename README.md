# 🎂 For Someone Special ❤️

An interactive, animated birthday website created to celebrate someone special through memories, heartfelt messages, beautiful animations, and personal moments.

## 💖 About the Project

**For Someone Special** is a personalized birthday surprise website designed to make someone's birthday memorable. It combines romantic animations, interactive pages, floating photographs, heartfelt letters, and a surprise ending to create a unique digital experience.

The website is designed to feel like an interactive story rather than a simple birthday greeting.

## ✨ Features

- 🎀 Beautiful animated birthday introduction
- 💌 Personal love letter and heartfelt messages
- 🎂 Interactive birthday cake animation
- 📸 Floating memory gallery with personal photos
- 💗 Interactive Yes/No question
- 💕 Animated hearts, sparkles, and floating effects
- 📷 Selfie capture feature using the camera
- ☁️ Selfie upload using Supabase Storage
- 📱 Responsive design for mobile and desktop devices
- 🎨 Soft romantic colors and animated transitions

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling, animations, transitions, and responsive layouts
- **JavaScript** – Interactive features and dynamic effects
- **Supabase** – Storage backend for selfie uploads
- **Web Camera API** – Capturing selfies using the device camera

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Make sure all the images are inside the `photos` folder.
4. Open `index.html` using a browser or VS Code Live Server.
5. Navigate through the pages and enjoy the birthday experience.

## 📸 Memories

The website contains a dedicated memory section featuring personal photographs presented through animated floating photo cards.

The images are stored locally inside the `photos` directory and can easily be replaced with other pictures.

## 🔐 Selfie Upload

The project includes a selfie capture feature that allows visitors to:

1. Open the camera.
2. Capture a selfie.
3. Preview the captured photo.
4. Upload the photo to Supabase Storage.

Camera access requires permission from the browser.
